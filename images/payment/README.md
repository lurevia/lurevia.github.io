# Logos officiels des opérateurs de mobile money

Ce dossier est lu automatiquement par `PaymentLogo` (`src/components/checkout/PaymentLogo.tsx`).
Déposez ici les fichiers vectoriels officiels obtenus auprès de chaque opérateur
(kit presse / brand guidelines), avec ces noms exacts :

- `mvola.svg`
- `orange-money.svg`
- `airtel-money.svg`

Tant qu'un fichier est absent, l'interface affiche automatiquement un badge de
repli aux couleurs de la marque (aucune rupture visuelle), donc l'intégration
de ces fichiers peut se faire à tout moment sans modifier le code.
